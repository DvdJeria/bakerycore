# Guía de Contribución

¡Gracias por tu interés en contribuir a BakeryCore! Las siguientes pautas están diseñadas para asegurar un flujo de trabajo ordenado y profesional.

## Cómo Reportar un Error (Bug)
Si encuentras un error en la aplicación, por favor abre un Issue en GitHub detallando:
* Descripción clara del problema.
* Pasos para reproducirlo.
* Comportamiento esperado vs. comportamiento actual.
* Capturas de pantalla o logs de consola si aplica.

## Cómo Proponer una Mejora o Funcionalidad
1. Abre un Issue para discutir el cambio propuesto antes de escribir código.
2. Explica por qué es necesario y cómo se alinea con el propósito del proyecto.

## Flujo de Trabajo para Pull Requests (PR)
1. Haz un Fork del repositorio.
2. Crea una rama para tu característica o corrección:
   git checkout -b feature/nueva-funcionalidad
3. Realiza tus commits siguiendo convenciones claras (ej: feat:, fix:, refactor:).
4. Envía los cambios a tu fork y abre un Pull Request hacia la rama principal.
