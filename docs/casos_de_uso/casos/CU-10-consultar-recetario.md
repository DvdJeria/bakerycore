# CU-10: Consulta del Recetario Digital

## 1. Descripción General
* **Actor Principal:** Operador.
* **Precondición:** Existen recetas digitalizadas en el sistema.
* **Descripción Breve:** Ofrece una interfaz visual táctil optimizada para buscar, visualizar y revisar paso a paso las preparaciones en reemplazo del cuaderno físico.

## 2. Flujo Principal (Camino Feliz)
1. El usuario abre el módulo de Recetario Digital.
2. Utiliza los filtros o la barra de búsqueda para localizar una preparación específica.
3. Selecciona la receta deseada.
4. La aplicación despliega la ficha completa con la fotografía del producto, listado de ingredientes y las instrucciones de preparación de manera limpia y legible.
