# CU-07: Cálculo de Costos y Sugerencia Comercial

## 1. Descripción General
* **Actor Principal:** Operador.
* **Precondición:** Existen materias primas registradas y con costos vigentes.
* **Descripción Breve:** Permite seleccionar insumos y definir cantidades para calcular el costo base de producción y aplicar una regla comercial sugerida.

## 2. Flujo Principal (Camino Feliz)
1. El usuario ingresa a la sección de cotización y selecciona "Nuevo Cálculo".
2. Agrega los ingredientes necesarios y especifica las cantidades requeridas para la preparación.
3. El sistema calcula en tiempo real el costo base sumando las proporciones de los insumos seleccionados.
4. El sistema aplica una regla de tres (relación entre costo base y proporción utilizada) para proyectar y sugerir un precio de venta comercial de referencia.
5. El operador revisa el desglose financiero detallado en pantalla antes de proceder a guardar el registro.
